# Configuration

QuickFavorites keeps user-specific data under `%USERPROFILE%\QuickFavorites`.

- `Menu\` contains the items shown by the launcher.
- `settings.json` stores the launcher's position and locked state.

These files are created/used locally and should not be uploaded to the public repository. Put your own shortcuts and documents in the local `Menu` folder; do not publish personal or confidential content.
